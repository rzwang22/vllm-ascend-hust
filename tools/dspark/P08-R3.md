## 三条路径与生命周期审计

| 路径 | core/model state 行为 | metadata 构造入口 |
| --- | --- | --- |
| 普通 eager | `AscendModelState.prepare_attn(for_capture=False)` | `build_attn_metadata` → DSA `build` |
| FULL warmup | `create_forward_fn(warmup=True)` → `prepare_inputs_to_capture` → `prepare_attn(for_capture=True)` | `build_attn_metadata(for_cudagraph_capture=True)` → DSA capture builder → `build` |
| FULL 实际 capture | core 再次调用 `create_forward_fn(warmup=False)`，重新执行同一准备链 | 新一次 capture metadata 构造，随后才进入硬件 graph context |

冻结 core 的 `prepare_inputs_to_capture()` 对两次准备都传 `CUDAGraphMode.NONE` 和
`for_capture=True`；因此不能凭 runtime mode=NONE 把这条路径视为普通 eager。
core `CudaGraphManager.capture()` 保留两份 warmup/captured attention state。
`AscendModelState` 只在整次构造成功后更新 `self.attn_metadata`；异常时保留之前的完整结果。

旧 `build_attn_metadata()` 已在函数入口创建三个 batch-local 空字典，但只向普通 build 传入。
capture 分支进入 core 的默认 `build_for_cudagraph_capture(common)`，默认方法再调用 build，
五项额外上下文全部丢失。只补 prefill 字典仍会遗漏 decode/common、实际请求数及 KV block size。

修复让两条分支使用同一套 DSA 参数：

- `num_reqs_actual=num_reqs`，沿用既有 MRV2 的请求数契约；
- `prefill_ratio_to_sas_metadata`、`decode_ratio_to_sas_metadata`、`common_ratio_to_sas_metadata`；
- 当前 `attn_group.kv_cache_spec.block_size`，不取外层 KV group 或全局 cache 默认值。

三个字典仍每次调用新建，在同一次构造的各 KV/attention groups 间传递同一对象。
空字典是合法初始化，DSA build 会填入 split/rope 和各 compression ratio 的 SAS 结果。
若某个专用 builder 替换字典，后续 group 采用它返回到 builder 属性上的对象，普通/capture 路径一致。
下一次 warmup、实际 capture、普通执行或失败后重试都重新初始化，不读取旧 builder 缓存作为输入。
这不复制或更改已有 NPU 常驻 tensor buffers 的生命周期。

DSA 新增显式五参数的 `build_for_cudagraph_capture()`，保持父类的
`build(common_prefix_len=0, common_attn_metadata=...)` 语义和 fast_build 默认值，完整转交上下文。
未改动旧 `build_for_graph_capture()` 的 DecodeOnly/SpecDecoding 专用语义。
MRV2 仍调用 backend 的 capture 入口；非 DSA backend 收不到 DSA 参数，其专用 capture override 继续生效。
普通执行的 model-specific kwargs 回调保留，capture 不新增对该普通执行回调的调用。
DSA `build()` 保留三组 metadata 断言，并将 block_size 改为必需键，遗漏时报错，不回落到 128。
现有 V1 runner 和压缩模型 proposer 已显式传 block_size，无需修改。

K=5 的 target verification query length 为 6。Ascend dummy batch 沿用 core 的 query/seq length，
`is_prefilling=False`；本次没有改写 dummy shape 或 prefill/decode 判定。P1 capture sizes 固定 `[6]`。
